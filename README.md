# WebSnabb Agency Website

Official production repository for **WebSnabb** — a modern freelance web design & engineering agency based in Mariehamn, Åland Islands.

## Features
- **Zero Frameworks:** Pure HTML5, CSS Custom Properties, and ES6+ JavaScript.
- **Lightweight & High Performance:** Target Lighthouse score > 95.
- **Internationalization (i18n):** Native client-side switching between English (`en`), Swedish (`sv`), and Finnish (`fi`) without page reloads.
- **Dual Themes:** Light and Dark Mode toggle with `localStorage` persistence and `prefers-color-scheme` support.
- **Mobile-First UX:** Adaptive sticky bottom navigation bar on mobile viewports (< 768px).
- **Accessibility & SEO:** WCAG AA compliant contrast ratios, keyboard skip-links, JSON-LD local business schema, dynamic meta tags.

## Development & Deployment

To run locally or deploy to GitHub Pages:
1. Clone or download this repository.
2. Serve the directory using any static file server (or simply open `index.html` directly in a modern web browser).
3. To host via GitHub Pages, push the repository and enable Pages under Repository Settings -> Pages (Source: `/root`).
